UDトーク公開ページ用の2つのボタン

下のボタンを ブックマークバーにドラッグして入れてください。クリックはしません（ドラッグです）。

UD取り出し

ライブ比較パネルは、ブックマークではなく Chrome拡張として入れてください。 コードが大きく、ブックマークに入れても Chrome が実行できないことが確認されました。 拡張として入れるとクリックすら不要で、公開ページを開いた時点で自動的に表示されます。

Chrome拡張の入れ方（2分・1回だけ）

  1. Chrome のアドレス欄に chrome://extensions と入力して開く
  2. 右上の「デベロッパー モード」をONにする
  3. 「パッケージ化されていない拡張機能を読み込む」をクリック
  4. デスクトップの UD_YY の中の chrome_extension フォルダを選ぶ
  5. UDトークの公開ページを開き直す → パネルが自動で出る

閉じたいときはパネルの ×。もう一度出すときは option + U です。

ライブ比較パネルの使い方

  1. 公開ページを開き、「UD×YY ライブ比較」をクリック
  2. 右下にパネルが出る。UD側は自動で入り、喋るたびに更新される
  3. YYprobe のテキストだけ、パネルの緑の欄に貼り付ける
  4. 食い違いが出るので、UD案 / YY案 / ✎（自分で入力）を選ぶ
  5. 「決定してコピー」→ UDトークの編集画面に貼り付け
「自動取得: ON / 固定」ボタンが重要です。 判断している最中に次の発話が届くと、UD側が入れ替わって選択が消えてしまいます。 直し始めるときに「固定」に切り替え、貼り終わったら「ON」に戻す、という使い方をしてください。

「最新1件〜5件」で取り込む発話数を、「言い回しも表示」で隠れている差分の表示を切り替えられます。 パネルはタイトル部分をつかんで移動できます。

取り出しボタンの使い方

  1. UDトークの「ウェブで公開」ページ（live.udtalk.jp/…）を開く
  2. ブックマークバーの「UD取り出し」をクリック
  3. 右下にパネルが出て、最新3件のテキストが選択された状態で入る
  4. そのまま ⌘C（自動コピーできた場合は不要）
  5. 修正補助ツールの UDトーク欄に ⌘V

「最新1件」「最新3件」「全部」で取り出す量を切り替えられます。× でパネルを閉じます。

なぜ必要か

公開ページの漢字にはふりがな（ルビ）が付いています。普通に選択してコピーすると 「担当たんとう」「思おもいます」のようにルビが本文に混ざってしまい、差分比較が壊れます。 このボタンはルビを取り除いた素のテキストだけを取り出します。

あわせて設定しておくこと

公開ページ右上の歯車（⚙）から「途中経過なし」をONにしておくと、 認識中の未確定テキスト（...）が出なくなり、確定した文だけを取り出せます。 観客に見せる画面とは別に、自分がコピーする画面だけこの設定にしておくのがおすすめです。

ブックマークバーが出ていないとき

Safari：メニューの「表示」→「お気に入りバーを表示」
Chrome：⌘⇧B

うまく動かないとき

UDトーク側のページ構造が変わると取り出せなくなることがあります。 その場合はパネルが空になるので、従来どおり UDトーク編集画面からコピーしてください。 （このボタンは補助であり、無くても運用は止まりません）

# UDトーク × YYprobe 半自動修正補助ツール

YYprobe の正確な文字起こしを「正」として、UDトークの誤りだけを直すための補助アプリ。
イベント本番（9月13日）で、運営が最短の手数で字幕を直せることを最優先に作っている。

---

## クイックスタート

### 必要な環境
- **macOS**（Python 3.8 以上・標準の `/usr/bin/python3` でそのまま動く）
- **インストール作業なし**：追加ライブラリは不要（tkinter と pbcopy/pbpaste だけを使用）

### 起動方法

Finder で `起動.command` をダブルクリック。または：

```bash
python3 uy_transcription_corrector.py
```

> ⚠️ 初回だけ macOS が「開発元を確認できません」と出ることがあります。
> `起動.command` を右クリック →「開く」→「開く」で許可してください。

### 動作確認（差分ロジックのテスト）

```bash
python3 test_diff_engine.py
```

`OK` と出れば正常。GUI を開かずに確認できるので、本番前のチェックに使う。

## 画面の使い方

```
┌─────────────────────┬─────────────────────┐
│ UDトーク（修正する側） │ YYprobe（正しい側）  │  ← ここに貼り付ける
├─────────────────────┼─────────────────────┤
│ 修正候補（採用/不採用） │ プレビュー（緑＝直る）│  ← 候補をクリックで切替
├─────────────────────┴─────────────────────┤
│ 修正済みテキスト → 「コピー」してUDトークへ  │
└───────────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| 左「UDトーク」 | UDトーク編集画面からコピーしたテキストを貼る |
| 右「YYprobe」 | YYprobe の正しいテキストを貼る |
| 修正候補リスト | 検出した差分。**緑＝採用**。クリックで採用／不採用を切り替え |
| プレビュー | 採用中の修正を当てた結果。緑背景が直る部分 |
| 修正済みテキスト | そのまま UDトークに貼れる最終形（手で直してもよい） |
| コピー | 修正済みテキストをクリップボードへ |
| UD欄に反映して次へ | 修正済みを左に移し、右を空にして次の発話へ |
| サンプル読込 | 練習用の例を順に読み込む（スタッフ練習・動作確認用） |
| 大きく＋／小さく－ | 文字サイズ変更（会場の見え方に合わせる） |
| 句読点の違いは無視 | ON なら「、。」や全半角の差は差分に出さない（既定 ON） |
| 自動で比較 | ON なら貼り付けた瞬間に比較（既定 ON） |

### ショートカット
| キー | 動作 |
|------|------|
| `⌘1` / `⌘2` | UD 欄／YY 欄にカーソル移動 |
| `⌘R` | 差分を検出 |
| `⌘⇧C` | 修正済みテキストをコピー |
| `⌘0` | リセット |

## 当日の運用フロー

```
1. YYprobe の正しいテキストをコピー
     ↓
2. アプリの右欄に貼り付け（⌘2 →⌘V、または「貼り付け」ボタン）
     ↓
3. UDトーク編集画面の誤字テキストをコピー
     ↓
4. アプリの左欄に貼り付け（⌘1 → ⌘V）
     ↓
5. 修正候補が自動で出る。直したくないものはクリックで外す
     ↓
6. ⌘⇧C でコピー
     ↓
7. UDトークに貼り付け
     ↓
（次の発話へ。「UD欄に反映して次へ」を押すと欄が整う）
```

**重要：** 全文置換ではなく「変更点ごとの採用」方式。
UD 側が正しい箇所や、UD で入れた表記はそのまま残る。

## トラブルシューティング

### Q. `起動.command` をダブルクリックしても何も出ない
ターミナルから直接実行してエラーを確認：
```bash
cd ~/Desktop/UD_YY && python3 uy_transcription_corrector.py
```

### Q. 「貼り付け」ボタンが効かない
クリップボードが空か、他アプリがコピーを完了していない可能性。
テキスト欄を直接クリックして `⌘V` でも貼り付けられる。

### Q. 差分が細かすぎる／大きすぎる
`diff_engine.py` の `compare(..., gap=1)` を調整する。
`gap` を大きくすると近い変更同士がまとまり、小さくすると細かく分かれる。

### Q. 直したくない箇所まで直ってしまう
修正候補リストでその項目をクリックして選択を外す（グレーになる＝不採用）。
「すべて不採用」を押せば UD 原文がそのまま残る。

### Q. 句読点の違いばかり出てくる
「句読点の違いは無視」を ON にする（既定 ON）。

### Q. 本番でアプリが落ちた
アプリ無しでも運用は止まらない。UDトーク編集画面で従来どおり手修正に切り替える。
アプリは補助であり、字幕配信そのものには関与しない。

## 技術仕様

### 構成
```
uy_transcription_corrector.py   # GUI（tkinter・標準ライブラリのみ）
diff_engine.py                  # 差分ロジック（GUI非依存・単体テスト可能）
test_diff_engine.py             # 単体テスト 13 件
testdata/samples.json           # 練習用サンプル（誤認識の実例を追記していく）
起動.command                     # ダブルクリック起動用
legacy_pysimplegui_prototype.py # 初版プロトタイプ（PySimpleGUI 版・参考用）
```

### 差分検出
- 比較前に正規化：空白・句読点を無視（任意）、NFKC で全半角を揃える。
  正規化後の位置は原文の位置に戻すので、**表示・置換は常に原文ベース**。
- `difflib.SequenceMatcher` を文字単位で適用。
  日本語では差分が細切れになるため、間の一致が `gap` 文字以下なら 1 件に結合する。
- 各変更は `replace` / `delete` / `insert` として保持し、**採用したものだけ**を
  UD 原文に差し込んで修正済みテキストを作る（`apply_changes`）。

### 性能
数百〜数千文字であれば体感ゼロ。貼り付け後 350ms のデバウンスで自動比較する。
